Work waiting to be taken, in the order it came. A work queue holds items, each standing for one issue (`agentic.tracking.issue`) or one task (`agentic.work`). A principal claims a waiting item and holds it until it finishes it or releases it back; only the claimer finishes or releases. The queue publishes when each item joined (`enqueued_at`), the order it is meant to be taken in. A closed queue takes no new item.
