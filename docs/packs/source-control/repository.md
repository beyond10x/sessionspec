A history of files kept by a forge. A repository holds revisions, each a snapshot of files named by the version control system (`agentic.workspace.Revision`) with the digest of its tree and its parent revisions; and references, the names that point at a revision. A movable reference (what a version control system calls a branch) is moved only from the revision its mover last saw, so two writers never overwrite each other; a fixed reference (a tag) never moves. A checkout binds a workspace (`agentic.workspace`) to a repository and a reference, which is how an agent's files come from and go back to a repository. An archived repository takes no new revision, reference or checkout.
