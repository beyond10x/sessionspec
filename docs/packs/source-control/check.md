An automated verdict on one revision of a repository: a build, a test suite, a linter, a whole pipeline. A check run is queued for a revision, starts (optionally as an instance of a workload, `agentic.runtime`), and completes once with an outcome; a queued or running check may be cancelled. A check run never changes after it completes; a new verdict is a new run.
