The conceptual tool run_command: run one command line in a workspace (`agentic.workspace`) under a live lease of it, with a time limit. A command run starts, then ends once: it exits with a code and the digest of its output, runs out of time, or is killed. It may change any file of the workspace; which files it changed is not known before it ran, so the file tools (`agentic.files`) record what a harness observes afterwards. A run may name the tool call of a harness session (`agentic.harness`) and the work run (`agentic.work`) it belongs to. Which shell plays the tool is a binding, not this block.
