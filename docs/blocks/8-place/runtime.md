What runs a workload. A runtime says which kinds of workload it runs and the least isolation it runs them under. A workload is a package by digest, a shape and the sandbox it runs in; an instance is one running copy, started, observed and stopped. A Model workload serves one endpoint of agentic.model; its instance's state is the endpoint's phase (Pending starting, Running ready, Exited stopped), and its start may cost money, booked against a budget. A compute cloud and an agent runtime each play this block; neither is described here.

## Settings

The settings a part of this block carries in an architecture document. `agenticspec sim check` refuses any other setting (`setting_unknown`) and a value outside its type (`setting_invalid`); the contract copies a setting into the ports it narrows. The last rows of each table are the settings every part takes. What no setting here types (a file, a path, an audience, the use of a model) goes into the part's `notes`, a map with free keys and values that the check takes as written and nothing reads.
