The specification declares 24 blocks in 11 layers, with 73 entities, 202 commands and 199 events. A block uses only blocks of its own layer or a lower one: an arrow points from a block to a block it depends on. The foundation, `shared`, holds the identifiers, content and money types every block uses; its arrows are left out.

## Packs and fields

These blocks are the core: what every agentic system has. Above them, [packs](../packs/index.md) hold the blocks more than one field of work reuses (source control, tracking, file tools, a shell), and [fields](../fields/index.md) name one kind of work, the packs it uses and its example architectures. No core block depends on a pack or a field.
