A message that needs an answer. A question offers lettered options, names the option it takes by default and a deadline; past the deadline the default is taken. Only the addressee, or a delegate acting for it, answers. A reply that could not be read is recorded as could not read, and the default is not taken in its place. An approval is a question whose two options are approve and reject.
