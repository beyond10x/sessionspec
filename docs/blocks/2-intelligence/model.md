What a model is and how it is reached. A provider offers models; a model has capabilities, a context window and a price per token class; an endpoint is where one model is served; a route is a name that resolves to one endpoint and model. An inference is one request on a route with its usage, latency and outcome. A retired route accepts no new inference.
