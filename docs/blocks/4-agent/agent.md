The definition of an agent. An agent is a principal of kind Agent with a name. Its behaviour is fixed by an immutable revision: a role, instructions held as content, a model or route for each use, the tools it may call, the knowledge it is given and its budget limits. A change is a new revision, never an edit. A revision is published, may be retired, and a retired revision is refused wherever it would be used.
