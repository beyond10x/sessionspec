The loop that turns a model into an agent: it sends the context to a model, takes the answer, runs tools, compacts the context when it grows, and stops. A harness is of one kind: a vendor's loop run as it ships, a loop driven from outside, or a loop native to this system. A harness session is one agent revision running in a harness for a principal. A sub-agent is a session whose parent is another session, so sessions form a tree with a depth that the harness bounds. Every model call of a session is a turn, with the inference it made and its usage. Every call of a tool by a session is a tool call: requested, decided (allowed or denied, with who decided), and then completed, failed, or recorded as could not read when its result could not be read; a call of a withdrawn tool is refused, and a call that was not allowed cannot complete. A session opens in a permission mode a field of work or a binding registered; the core names no mode. A session that restarts an ended one names it, and the chain of restarts is its lineage.

## Settings

The settings a part of this block carries in an architecture document. `agenticspec sim check` refuses any other setting (`setting_unknown`) and a value outside its type (`setting_invalid`); the contract copies a setting into the ports it narrows. The last rows of each table are the settings every part takes. What no setting here types (a file, a path, an audience, the use of a model) goes into the part's `notes`, a map with free keys and values that the check takes as written and nothing reads.

A part `harness`:

| setting | type | unit | default | contract | what |
|---|---|---|---|---|---|
| `kind` | string |  |  | every port | The kind of harness, a row a field registers. |
| `count` | integer of at least 0 |  | `1` |  | How many copies of the part run. |
| `per` | part |  |  |  | One copy of the part for each copy of the named part. |
| `notes` | notes |  |  |  | Free notes on the part, a map with keys and values of any kind: what no setting of its block types. The check takes any map; the simulator, the search and the contract never read it. |
