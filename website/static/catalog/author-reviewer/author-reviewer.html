Architecture · optimization result

author-reviewer

Workers write; a reviewer agent checks every task a worker reports done and sends a rejected one back for rework. An author-reviewer loop cost $0.95-1.07 per file against $1.98-2.91 for a multi-agent workflow (2610.09995); required review sub-agents raised the defects reported from 49.9% to 69.6% (2609.20812). The simulator models the reviewer by its false-accept and false-reject rates (2611.02207) and the cost of its model calls; it does not model a reviewer that misses planted harm (2611.00689) apart from those rates, nor a reviewer that teaches a worker.
